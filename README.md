Эмулятор для языка оболочки ОС. Вариант №10.

Проект выполнен студентом группы ИКБО-20-25
Журавлёвым З.А.

## О программе

OSEmulator — эмулятор для языка оболочки ОС.

Приложение реализовано в форме консольного интерфейса (CLI).
Приглашение к вводу содержит имя текущей виртуальной
файловой системы (VFS).

## Этапы

### Этап 1. REPL

Реализовано:

- Консольный интерфейс (CLI).
- Приглашение к вводу содержит имя VFS.
- Парсер аргументов с поддержкой кавычек.
- Команды-заглушки `ls` и `cd`.
- Команда `exit`.
- Обработка ошибок (неизвестная команда, непарные кавычки).

### Этап 2. Конфигурация

Реализовано:

- Параметры командной строки `--vfs` и `--script`.
- Отладочный вывод всех заданных параметров при запуске.
- Выполнение стартового скрипта с остановкой при первой
  ошибке. На экран выводится как ввод, так и вывод
  (имитация диалога с пользователем).
- Скрипты реальной ОС (`.bat`) для тестирования всех
  поддерживаемых параметров командной строки.

## Требования

- Python 3.10 или выше.

## Сборка

Сборка не требуется. Проект запускается интерпретатором
Python 3.

## Запуск приложения

Интерактивный режим (Windows):

```bat
run.bat
```

Универсально:

```bash
python src/main.py
```

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | Путь к физическому расположению VFS. |
| `--script PATH` | Путь к стартовому скрипту. |

Параметры опциональны. Если `--script` задан, эмулятор
выполнит скрипт и завершится. Иначе запустится
интерактивный режим.

## Запуск тестов

```bash
python -m unittest discover -s tests
```

## Поддерживаемые команды

### `ls`

На данном этапе команда реализована в виде заглушки.

Примеры:

```
my_vfs$ ls
ls: arguments = []

my_vfs$ ls a b c
ls: arguments = ['a', 'b', 'c']

my_vfs$ ls "my dir"
ls: arguments = ['my dir']
```

### `cd`

На данном этапе команда реализована в виде заглушки.

Примеры:

```
my_vfs$ cd
cd: arguments = []

my_vfs$ cd a b c
cd: arguments = ['a', 'b', 'c']

my_vfs$ cd "/home/user dir"
cd: arguments = ['/home/user dir']
```

### `exit`

Завершает работу приложения. Аргументы не поддерживаются.

```
my_vfs$ exit
Bye.
```

При передаче аргументов выводится ошибка:

```
my_vfs$ exit a b c
Error: exit: command takes no arguments
```

## Обработка ошибок

### Неизвестная команда

```
my_vfs$ test
Error: unknown command 'test'
```

### Ошибка разбора (непарные кавычки)

```
my_vfs$ ls "unbalanced
Error: parsing error: No closing quotation
```

## Стартовые скрипты

Стартовый скрипт — это текстовый файл, в каждой строке
которого записана команда эмулятора. Пустые строки
игнорируются. При первой ошибке выполнение скрипта
останавливается.

Пример (`scripts/demo.txt`):

```
ls
ls -la /home
cd "my folder"
exit
```

Запуск:

```bash
python src/main.py --script scripts/demo.txt
```

Отладочный вывод перед началом выполнения:

```
=== Debug: emulator parameters ===
  vfs path    = None
  script path = 'scripts/demo.txt'
===================================
my_vfs$ ls
ls: arguments = []
...
```

## Скрипты тестирования параметров

В папке `scripts/` находятся `.bat`-файлы для проверки
всех поддерживаемых параметров командной строки:

| Скрипт | Что проверяет |
|--------|---------------|
| `run_no_params.bat` | Запуск без параметров. |
| `run_with_vfs.bat` | Запуск с `--vfs`. |
| `run_with_script.bat` | Запуск с `--script`. |
| `run_with_both.bat` | Запуск с обоими параметрами. |
| `run_with_quotes.bat` | Скрипт с кавычками и ошибкой парсинга. |
