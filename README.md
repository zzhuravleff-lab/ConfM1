# OSEmulator

Эмулятор для языка оболочки ОС. Вариант №10.

Проект выполнен студентом группы ИКБО-20-25
Журавлёвым З.А.

## О программе

OSEmulator — эмулятор для языка оболочки ОС.

Приложение реализовано в форме консольного интерфейса (CLI).
Приглашение к вводу содержит имя текущей виртуальной
файловой системы (VFS).

## Этапы

### Этап 1. REPL

Реализовано:

- Консольный интерфейс (CLI).
- Приглашение к вводу содержит имя VFS.
- Парсер аргументов с поддержкой кавычек.
- Команды-заглушки `ls` и `cd`.
- Команда `exit`.
- Обработка ошибок (неизвестная команда, непарные кавычки).

### Этап 2. Конфигурация

Реализовано:

- Параметры командной строки `--vfs` и `--script`.
- Отладочный вывод всех заданных параметров при запуске.
- Выполнение стартового скрипта с остановкой при первой
  ошибке. На экран выводится как ввод, так и вывод
  (имитация диалога с пользователем).
- Скрипты реальной ОС (`.bat`) для тестирования всех
  поддерживаемых параметров командной строки.

### Этап 3. VFS

Реализовано:

- Загрузка виртуальной файловой системы из XML-файла
  в память.
- Все операции — в памяти, источник не модифицируется.
- Вывод сообщения из файла `motd` при старте, если он
  есть в корне VFS.
- Скрипты реальной ОС для тестирования различных
  вариантов VFS: минимальный, несколько файлов,
  3+ уровня вложенности, а также случаи ошибок.
- Стартовый скрипт `scripts/startup_full.txt` для
  тестирования всех команд.

## Формат XML для VFS

```xml
<?xml version="1.0" encoding="UTF-8"?>
<vfs name="multi">
  <file name="motd">Welcome!</file>
  <dir name="home">
    <file name="readme.txt">Hello</file>
  </dir>
</vfs>
```

- Корневой тег — `<vfs name="...">`.
- `<dir name="...">` — директория.
- `<file name="...">текст</file>` — файл.
- Файл `motd` в корне выводится при старте.

## Параметры VFS

`--vfs PATH` может указывать на:

- **XML-файл** — загружается напрямую.
- **Папку** — ищется `vfs.xml` или первый `*.xml`.

Если VFS не загрузилась (файл не найден, битый XML,
неверный корневой тег) — программа завершается
с кодом 1.

### Этап 4. Основные команды

Реализовано:

- Реальная работа команд `ls` и `cd` с загруженной VFS.
- Новые команды `echo`, `clear`, `history`.
- Поддержка относительных путей, а также `.` и `..`.
- Если VFS не загружена, создаётся пустая VFS в памяти.

## Команды

### `ls [path]`

Вывести содержимое директории или имя файла.

- Без аргумента — текущая директория.
- Имена через пробел в одну строку (алфавитный порядок).
- Для файла — имя файла.
- Ошибка: `ls: cannot access '...': No such file or directory`.
- Ошибка: `ls: too many arguments`.

Примеры:

```
my_vfs$ ls
etc home motd
my_vfs$ ls /home
notes.txt readme.txt
my_vfs$ ls /home/readme.txt
readme.txt
```

### `cd [path]`

Сменить текущую директорию.

- Без аргумента — переход в `/`.
- Поддерживает `.` и `..`.
- Ошибка: `cd: no such directory: ...`.
- Ошибка: `cd: not a directory: ...`.

Примеры:

```
my_vfs$ cd /home
my_vfs$ pwd_placeholder
```

### `echo [args...]`

Вывести аргументы через пробел.

- Без аргумента — пустая строка.
- Переменные не раскрываются.

Примеры:

```
my_vfs$ echo hello world
hello world
my_vfs$ echo $HOME
$HOME
```

### `clear`

Очистить экран.

- В стартовом скрипте — **no-op** (ничего не делает).

### `history`

Вывести историю выполненных команд.

- Формат: `   1  ls`.
- Сама команда `history` включается в вывод.
- Команды из стартового скрипта тоже попадают в историю.
- Ошибка: `history: too many arguments`.

## Стартовые скрипты Этапа 4

- `scripts/startup_stage4.txt` — полный прогон всех команд.
- `.bat`-скрипты: `run_stage4_full.bat`, `run_stage4_history.bat`.

## Запуск приложения

Интерактивный режим (Windows):

```bat
run.bat
```

Универсально:

```bash
python src/main.py
```

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | Путь к физическому расположению VFS. |
| `--script PATH` | Путь к стартовому скрипту. |

Параметры опциональны. Если `--script` задан, эмулятор
выполнит скрипт и завершится. Иначе запустится
интерактивный режим.

## Запуск тестов

```bash
python -m unittest discover -s tests
```

## Поддерживаемые команды

### `exit`

Завершает работу приложения. Аргументы не поддерживаются.

```
my_vfs$ exit
Bye.
```

При передаче аргументов выводится ошибка:

```
my_vfs$ exit a b c
Error: exit: command takes no arguments
```

## Обработка ошибок

### Неизвестная команда

```
my_vfs$ test
Error: unknown command 'test'
```

### Ошибка разбора (непарные кавычки)

```
my_vfs$ ls "unbalanced
Error: parsing error: No closing quotation
```

## Стартовые скрипты

Стартовый скрипт — это текстовый файл, в каждой строке
которого записана команда эмулятора. Пустые строки
игнорируются. При первой ошибке выполнение скрипта
останавливается.

Пример (`scripts/demo.txt`):

```
ls
ls -la /home
cd "my folder"
exit
```

Запуск:

```bash
python src/main.py --script scripts/demo.txt
```

Отладочный вывод перед началом выполнения:

```
=== Debug: emulator parameters ===
  vfs path    = None
  script path = 'scripts/demo.txt'
===================================
my_vfs$ ls
ls: arguments = []
...
```

## Скрипты тестирования параметров

В папке `scripts/` находятся `.bat`-файлы для проверки
всех поддерживаемых параметров командной строки и
вариантов VFS.

| Скрипт | Этап | Что проверяет |
|--------|:----:|---------------|
| `run_no_params.bat` | 2 | Запуск без параметров (интерактивный REPL). |
| `run_with_vfs.bat` | 2 | Запуск с `--vfs` (папка с XML). |
| `run_with_script.bat` | 2 | Запуск с `--script`. |
| `run_with_both.bat` | 2 | Запуск с обоими параметрами. |
| `run_with_quotes.bat` | 2 | Скрипт с кавычками и ошибкой парсинга. |
| `run_with_min_vfs.bat` | 3 | Минимальный VFS (одна папка). |
| `run_with_multi_vfs.bat` | 3 | VFS с `motd` и несколькими файлами. |
| `run_with_deep_vfs.bat` | 3 | VFS с 3+ уровнями вложенности. |
| `run_with_broken_vfs.bat` | 3 | Битый XML (ошибка парсинга). |
| `run_with_bad_format.bat` | 3 | Неверный корневой тег. |
| `run_vfs_and_script.bat` | 3 | VFS + стартовый скрипт (полный прогон). |
| `run_stage4_full.bat` | 4 | Полный прогон команд Этапа 4 (`ls`, `cd`, `echo`, `history`). |
| `run_stage4_history.bat` | 4 | Интерактивная проверка `history`. |
